# bg-video
 

A personalized version of a project inspired by HuXn-WebDev's 100 Days of HTML, CSS, and JavaScript series. This project features a unique design and additional functionality to enhance the original concept.

## Features
- Customized video with a z-index styling
- Unique text styling with animations
- Added letter-spacing and hover effects

## Inspiration
This project is inspired by HuXn-WebDev's tutorial on [YouTube](https://www.youtube.com/@HuXn-WebDev). While the core idea comes from the series, significant modifications have been made to personalize the design and functionality.

## Technologies Used
- HTML5
- CSS3
